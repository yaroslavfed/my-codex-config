# Память проектов

Эта папка хранит проверяемые заметки о сервисах. У каждого репозитория своя папка `projects/<имя-репозитория>/` с короткой обзорной заметкой `<имя-репозитория>.md`. Тематические заметки появляются по мере необходимости для устойчивых сценариев или областей ответственности, а не для каждого класса и метода.

## Открыть в Obsidian

Открой `projects/` как существующее хранилище Obsidian. [Карта сервисов](projects/Карта%20сервисов.md) связывает обзорные заметки репозиториев, а обзор связывает темы. Ссылки между сервисами сопровождаются описанием взаимодействия, чтобы граф показывал смысл, а не только соседство файлов. Обычный Markdown остаётся читаемым без Obsidian.

## Как поддерживать память

Инструкции агенту находятся в `../skills/project-memory/SKILL.md`. Сначала он читает обзор репозитория, затем нужные тематические заметки. Перед записью сверяет сведения с кодом и обновляет существующий пункт, если поведение изменилось. Источники, дата и ветка проверки в заметке с фактами помогают отличить подтверждённое знание от устаревшего. Целевые планы отделены от текущего поведения. Новая папка и обзор появляются при первом проверенном знании о репозитории; пустые тематические заметки не создаются.

Корень памяти находится рядом с `skills/`. При переносе скилла отдельно от этой папки агент сообщит о недоступной памяти и продолжит основную задачу.
