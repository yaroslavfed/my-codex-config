# Память проектов

Эта папка хранит проверяемые заметки о сервисах. Один репозиторий соответствует одному файлу `projects/<имя-репозитория>.md`; групп по продуктам и базе фактов нет.

## Открыть в Obsidian

Открой эту папку как существующее хранилище Obsidian. Ссылки на заметки, например [[elph-chat-server]], соединяют сервисы в графе. Ссылки между сервисами сопровождаются описанием взаимодействия, чтобы граф показывал смысл, а не только соседство файлов. Обычный Markdown остаётся читаемым без Obsidian.

## Заметки

- [[api-gateway]] — внешний HTTP-вход к chat-server
- [[elph-chat-server]] — сообщения, gRPC и доставка событий
- [[elph-bot-service]] — входящие события и маршрутизация ботов
- [[elph-bot-jarvis]] — бот и потоковый контракт с ИИ

## Как поддерживать память

Инструкции агенту находятся в `../skills/project-memory/SKILL.md`. Перед записью он сверяет сведения с кодом и обновляет существующий пункт, если поведение изменилось. Путь к файлу и дата проверки в каждой заметке помогают отличить подтверждённое знание от устаревшего. Новая заметка появляется при первом проверенном знании о репозитории, без пустого шаблона на каждый проект.

Корень памяти находится рядом с `skills/`. При переносе скилла отдельно от этой папки агент сообщит о недоступной памяти и продолжит основную задачу.
