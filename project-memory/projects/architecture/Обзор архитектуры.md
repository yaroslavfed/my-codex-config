# Обзор архитектуры

## Назначение

Эта папка содержит обзорные схемы Elph Nova. Markdown остаётся источником проверяемых сведений, Canvas показывает взаимодействия, а Local Graph помогает перейти к соседним заметкам.

## Условные обозначения

- Обычные карточки и стрелки описывают подтверждённое поведение
- Оранжевые карточки с пометкой «Ветка» отражают сведения, проверенные только в указанной рабочей ветке
- Фиолетовые карточки с пометкой «План» отражают согласованный целевой сценарий, которого нет в проверенном коде

## Навигация

Откройте Local Graph для обзорной или тематической заметки с глубиной 1. Увеличивайте глубину до 2, когда нужны связи через соседний сервис. Глобальный граф использует цветовые группы по папкам.

## Источники

Связи на схемах опираются на обзорные и тематические заметки хранилища. Статус, ветка и дата проверки указаны в самих заметках.
